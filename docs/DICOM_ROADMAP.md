# DICOM roadmap

Today the prototype accepts labelled JPEG/PNG demonstrations and stores private asset metadata separately from binary upload. The client quality gate detects only obvious file problems and never claims radiological validation.

The production path is DICOM ingestion, DICOMweb STOW-RS, QIDO-RS query, WADO-RS retrieval, and authorized PACS integration. This requires validated devices, de-identification rules, specialist viewing software, audit trails, and governance review.
